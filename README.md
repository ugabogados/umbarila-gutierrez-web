# Umbarila Gutiérrez & Asociados — Landing Web

Landing corporativa de Umbarila Gutiérrez & Asociados.

## Objetivo
Construir una landing jurídica profesional, rápida, responsive y orientada a conversión, con formulario de solicitud de información y despliegue sobre Cloudflare Pages.

## Stack previsto
- HTML5
- CSS3
- JavaScript
- GitHub para control de versiones
- Cloudflare Pages para hosting
- Cloudflare Worker para formulario
- Cloudflare Turnstile para protección anti-spam

## Estructura prevista
- Hero
- Áreas jurídicas
- La firma
- Equipo
- Cómo trabajamos
- Opiniones
- Preguntas frecuentes
- Formulario de contacto
- CTA final
- Footer
